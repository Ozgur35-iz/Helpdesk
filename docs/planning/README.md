# Planning docs

`project-scope.md`, `tech-stack.md`, and `implementation-plan.md` here are the original planning documents, written before implementation started. They describe an *intended* stack (Next.js, Auth.js, Tailwind/shadcn, Postmark/Mailgun, Claude API + pgvector) that the actual build diverged from as real constraints and trade-offs came up during development.

For what was actually built, see the [root README](../../README.md) and the root `CLAUDE.md`'s "Stack reality vs. planning docs" section, which tracks the divergence in detail (Bun/Vite/Express/better-auth instead of Next.js/Auth.js, Gemini instead of Claude/pgvector, etc.).

Kept for the record, not as current documentation.
